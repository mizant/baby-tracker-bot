# Быстрый старт 🚀

## Шаг 1: Установка Python

Убедитесь, что у вас установлен Python 3.12 или выше.

Проверьте версию:

```bash
python --version
```

Если Python не установлен, скачайте с https://www.python.org/downloads/

## Шаг 2: Настройка проекта

### Вариант A: Использование start.bat (Windows)

Просто запустите:

```bash
start.bat
```

Скрипт автоматически:

- Создаст виртуальное окружение
- Установит все зависимости
- Покажет следующие шаги

### Вариант B: Ручная установка

1. **Создайте виртуальное окружение:**

```bash
python -m venv venv
```

2. **Активируйте его:**

```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

3. **Установите зависимости:**

```bash
pip install -r requirements.txt
```

## Шаг 3: Настройка .env файла

1. Откройте файл `.env` (уже создан)

2. **Получите BOT_TOKEN:**

   - Откройте Telegram и найдите @BotFather
   - Отправьте команду `/newbot`
   - Следуйте инструкциям
   - Скопируйте полученный токен
   - Вставьте в `.env` вместо `your_bot_token_here`

3. **Узнайте свой Telegram ID:**

   - Найдите @userinfobot в Telegram
   - Отправьте любое сообщение
   - Скопируйте ваш ID (например: 123456789)
   - Вставьте в `.env` в `ADMIN_IDS`

4. **Настройте часовой пояс (опционально):**
   - По умолчанию: Europe/Warsaw
   - Для Москвы: Europe/Moscow
   - Для Киева: Europe/Kiev
   - Список: https://en.wikipedia.org/wiki/List_of_tz_database_time_zones

Пример .env:

```env
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
ADMIN_IDS=123456789,987654321
TIMEZONE=Europe/Moscow
DATABASE_URL=sqlite+aiosqlite:///./baby_tracker.db
```

## Шаг 4: Запуск бота

```bash
python -m app.main
```

Вы должны увидеть:

```
Starting Baby Tracker Bot...
Database initialized
Bot is running...
```

## Шаг 5: Проверка

1. Откройте вашего бота в Telegram
2. Отправьте `/start`
3. Вы должны получить главное меню с кнопками

## Возможные проблемы

### "BOT_TOKEN не найден"

- Убедитесь, что файл `.env` существует
- Проверьте, что `BOT_TOKEN` вписан правильно
- Убедитесь, что нет лишних пробелов

### "Доступ закрыт"

- Убедитесь, что ваш Telegram ID вписан в `ADMIN_IDS`
- ID должен быть числом, без кавычек
- Несколько ID разделяются запятой: `123456789,987654321`

### Ошибки при запуске

- Убедитесь, что виртуальное окружение активировано
- Проверьте, что все зависимости установлены: `pip install -r requirements.txt`
- Перезапустите терминал

### Бот не отвечает

- Проверьте, что токен правильный
- Убедитесь, что интернет-соединение активно
- Посмотрите логи в консоли на наличие ошибок

## Остановка бота

Нажмите `Ctrl+C` в терминале

## Повторный запуск

1. Активируйте виртуальное окружение:

```bash
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

2. Запустите бота:

```bash
python -m app.main
```

## Обновление

Если появились новые изменения в коде:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

## Структура данных

Бот создает файл `baby_tracker.db` автоматически при первом запуске.

В нем хранятся таблицы:

- `feedings` - кормления
- `sleep_sessions` - сессии сна
- `diapers` - подгузники
- `weights` - вес
- `events` - события для отмены

⚠️ **Важно:** Не удаляйте файл базы данных, если хотите сохранить историю!

## Резервная копия

Для сохранения данных скопируйте:

```
baby_tracker.db
```

## Поддержка

При проблемах смотрите логи в консоли. Все ошибки выводятся туда.
